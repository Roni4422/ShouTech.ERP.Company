## 1. نظرة عامة

**ShouTech ERP** منصة تجارية متكاملة لإدارة موارد المؤسسات (Enterprise Resource Planning)، موجّهة للشركات الصغيرة والمتوسطة والمؤسسات التي تحتاج:

- محاسبة ومالية عامة (General Ledger)
- مستودعات ومخزون
- مبيعات ومشتريات وفواتير
- نقاط بيع (POS)
- عملاء وعلاقات (CRM)
- تصنيع
- موارد بشرية
- تقارير وتحليلات
- أمان وصلاحيات ومراجعة (Audit)

يعمل البرنامج **أوفلاين أولاً (Offline-First)** مع إمكانية المزامنة والنسخ الاحتياطي عند توفر الشبكة، دون عرض تفاصيل الخادم أو المزامنة للمستخدم النهائي في واجهة التشغيل.

## 4. كيف يعمل البرنامج — دورة التشغيل

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  تشغيل EXE  │───▶│  اختيار     │───▶│  SplWin     │───▶│  ComWin     │───▶│  LogWin     │
│  App.xaml   │    │  اللغة Lang │    │  (Splash)   │    │  (شركة)     │    │  (دخول)     │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                                                    │
                                                                                    ▼
                                                                            ┌─────────────┐
                                                                            │  MWin       │
                                                                            │  (الرئيسية) │
                                                                            └─────────────┘
```

### 4.1 مراحل الإقلاع

1. **Mutex — نسخة واحدة**  
   يمنع تشغيل أكثر من نسخة على نفس الجهاز (`AllowMultipleInstances: false`).

2. **AppHost.Initialize()**  
   تحميل الإعدادات، الثيم، الخدمات (ترخيص، اتصال، نسخ احتياطي، مزامنة).

3. **اختيار اللanguage (أول تشغيل)**  
   نافذة `Lang` — العربية، English، Français، Türkçe.

4. **SplWin — شاشة التمهيد**  
   تهيئة الخدمات أوفلاين، شريط تقدم، مدة عرض دنيا (`MinSplashSeconds`).

5. **ComWin — اختيار الشركة**  
   دعم تعدد الشركات (`MultiCompany`).

6. **LogWin — تسجيل الدخول**  
   مصادقة المستخدم، تذكّر آخر مستخدم، مستويات: Administrator / User / Viewer.

7. **MWin — النافذة الرئيسية**  
   قائمة علوية + Ribbon + منطقة عمل + شريط حالة.

### 4.2 هيكل النافذة الرئيسية (MWin)

| المنطقة | الوظيفة |
|---------|---------|
| **Menu Bar** | 17 قائمة رئيسية (ملف، مستودعات، حسابات، …) |
| **Toolbar** | حفظ، تراجع، طباعة، بحث، ثيم، خروج |
| **Ribbon** | أوامر مجمّعة حسب التبويب (215+ أمر في الكatalog) |
| **Content** | لوحة القيادة أو وحدة العمل (`ModWsVw`, `DashVw`) |
| **Status Bar** | حالة (إنجليزي)، شركة، إصدار، مستخدم، وقت |

> **ملاحظة:** شريط الحالة يعرض نصوصاً **إنجليزية ثابتة** عبر `StatBarEn` ولا يكشف حالة السيرفر أو المزامنة.

## 6. الأمان والصلاحيات

### 6.1 مستويات المستخدم

| المستوى | الكود | الصلاحيات |
|---------|-------|-----------|
| **Administrator** | `admin` | كامل — إعدادات، أمان، نسخ احتياطي |
| **User** | `user` | تشغيل يومي — حفظ وتعديل حسب RBAC |
| **Viewer** | `viewer` | عرض فقط — لا حفظ |

### 6.2 RBAC (Role-Based Access Control)

- جداول `sec.Users`, `sec.Roles`, `sec.Permissions`  
- ربط أوامر Ribbon بـ `PERM_NAV_*` في `sds_nav.sql`  
- `PermServ.HasPermission(key)` في طبقة التطبيق

### 6.3 أمان إضافي (حسب الإعداد)

- تشفير AES-256 للبيانات الحساسة  
- سجل مراجعة (Audit) — 365 يوم احتفاظ  
- كلمات مرور: طول 8+، أحرف كبيرة/صغيرة/أرقام  
- دعم 2FA (اختياري)  
- Dongle / Hardware ID للترخيص  
- فحص سلامة الملفات (`CheckFileIntegrity`)

### 7.2 التقنيات

| الطبقة | التقنية |
|--------|---------|
| **UI** | WPF (.NET 8), Ribbon, MVVM (CommunityToolkit.Mvvm) |
| **ORM / Data** | Microsoft.Data.Sqlite / Npgsql |
| **i18n** | JSON (Ar, En, Fr, Tr) + RTL/LTR |
| **Logging** | Serilog + ملفات في `%LocalAppData%\ShouTech\ERP\logs` |
| **Backup** | ZIP دوّار محلي + رفع اختياري للسيرفر |
| **Security Engine** | C++20 (PROT.dll / Dongle) — اختياري |
| **AI** | Ollama / FastAPI محلي (اختياري) |
| **Reports** | FastReport .NET (مخطط) |

### 7.3 مسارات مهمة على الجهاز

| المسار | المحتوى |
|--------|---------|
| `%LocalAppData%\ShouTech\ERP\cfg\` | `user.dat`, `license.local.json`, `device.json` |
| `%LocalAppData%\ShouTech\ERP\logs\` | `app_YYYYMMDD.log`, `crash_*.log` |
| `%LocalAppData%\ShouTech\ERP\sync\` | لقطات مزامنة (داخلية — غير معروضة للمستخدم) |
| `{App}\bkp\` | نسخ احتياطية دوّارة |
| `{App}\Resources\Lang\` | Ar.json, En.json, Fr.json, Tr.json |

## 9. النسخ الاحتياطي والمزامنة

| الميزة | السلوك |
|--------|--------|
| **نسخ محلي** | 10 نسخ FIFO (`bkp/backup_current.zip`) |
| **نسخ سحابي** | حتى 3 نسخ مشفّرة (عند الاتصال) |
| **مزامنة** | طابور خلفي كل 3600 ثانية — **سرّي في UI** |
| **Startup backup** | نسخة عند الإقلاع إذا الشبكة متاحة |
| **Offline-First** | كل العمليات الأساسية بدون إنترنت |
